## Web Application Security Assessment

### Authorized Web Application VAPT Assessment

- **Category:** Web Application Security / VAPT
- **Authorization:** Written institutional authorization
- **Date:** November 27, 2026
- **Status:** Assessment completed

**Project Overview**

Conducted an authorized web application security assessment focusing on publicly accessible application security configurations, transport security, session management attributes, and client-side form controls.

**Assessment Areas**

- DNS and hosting boundary analysis
- HTTP and HTTPS configuration
- HTTP security header inspection
- TLS certificate and protocol analysis
- Session cookie security attributes
- Client-side CAPTCHA and CSRF observations
- URL routing and response behaviour
- Front-end library identification

**Documented Findings**

The assessment documented six findings:

| Finding ID | Security Observation | Severity |
|---|---|---|
| VAPT-01 | Missing HTTP Security Headers | Low |
| VAPT-02 | Unhardened PHPSESSID Cookie | Low |
| VAPT-03 | Temporary HTTPS Redirect | Low |
| VAPT-04 | Client-Side CAPTCHA & No CSRF Token | Low |
| VAPT-05 | Soft-200 Routing & OG Path Concatenation | Informational |
| VAPT-06 | Outdated Front-End Library | Informational |

**Positive Security Observations**

- Valid wildcard TLS certificate.
- Deprecated TLS 1.1 protocol disabled.
- Server version information suppressed.
- Contact form using HTTPS transport.

**Tools Used**

Nmap, WhatWeb, cURL, OpenSSL, DNS utilities, WHOIS, Kali Linux, and Firefox Developer Tools.

**Documentation & Report**

[View Authorized Web Application VAPT Project](https://github.com/fairoocm/SOC-Analyst-Portfolio/tree/main/authorized-web-security-assessment)
